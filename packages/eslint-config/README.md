# `@brickninja-org/eslint-config`

Common ESLint configs for the [BrickNinja](https://github.com/brickninja-org) org.


## Usage

### Common (Typescript)
```json
{
  "extends": ["@brickninja-org/eslint-config"]
}
```

### React

Also includes the common config

```json
{
  "extends": ["@brickninja-org/eslint-config/react"]
}
```


## Installation

```
npm i -D @brickninja-org/eslint-config
```
